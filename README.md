# Qadam AI — тренировочный проект HackAlem AI

AI-агент, который превращает описание жизненной ситуации в понятный маршрут получения государственной услуги.

Проект выполняется как симуляция хакатона одним участником, который последовательно работает в трёх ролях:

- Product Captain — проблема, приоритеты, README и питч;
- AI / Backend — агентный сценарий, данные и API;
- Frontend / UX — интерфейс, демонстрация и проверка пользовательского пути.

## Стек

- Python 3.14 standard library;
- HTML, CSS и vanilla JavaScript;
- JSON-каталог проверенных услуг;
- `unittest` для автоматических проверок.

## Статус

Часы 1–2 завершены: спроектирован и реализован рабочий вертикальный прототип. Главный сценарий проходит два уточнения и возвращает маршрут из проверенной записи каталога.

## Локальный запуск

```powershell
python app.py
```

Откройте `http://127.0.0.1:8000`.

Приложение не требует установки пакетов.

### Включение AI-классификации

API-ключ не хранится в репозитории. Перед запуском задайте его и выбранную модель только в текущем терминале:

```powershell
$env:OPENAI_API_KEY = "ваш API-ключ"
$env:OPENAI_MODEL = "модель, доступная вашему API-проекту"
python app.py
```

Если переменные не заданы или запрос к API завершился ошибкой, включается локальный fallback. Модель выбирает только идентификатор услуги; документы и шаги всегда берутся из проверенного каталога.

## Тесты

```powershell
python -m unittest discover -s tests -v
```
