# Qadam AI — тренировочный проект HackAlem AI

AI-агент, который превращает описание жизненной ситуации в понятный маршрут получения государственной услуги.

Проект выполняется как симуляция хакатона одним участником, который последовательно работает в трёх ролях:

- Product Captain — проблема, приоритеты, README и питч;
- AI / Backend — агентный сценарий, данные и API;
- Frontend / UX — интерфейс, демонстрация и проверка пользовательского пути.
