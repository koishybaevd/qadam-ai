# Текстовый wireframe

## Один экран

```text
+------------------------------------------------------------+
| Qadam AI                         [Русский | Қазақша]        |
| Понятный маршрут государственной услуги                    |
+------------------------------------------------------------+
| Опишите ситуацию своими словами                            |
| +--------------------------------------------------------+ |
| | Я переехал в Астану и хочу зарегистрироваться...       | |
| +--------------------------------------------------------+ |
|                                             [Найти маршрут] |
+------------------------------------------------------------+
| Уточнение                                                  |
| У вас есть согласие собственника жилья?                    |
| [Да] [Нет] [Не знаю]                                       |
+------------------------------------------------------------+
| Регистрация по месту жительства              [Подходит]    |
| Почему: ...                                                |
|                                                            |
| Что подготовить                                            |
|  □ Документ или условие                                    |
|                                                            |
| Что делать                                                 |
|  1. Первый шаг                                             |
|  2. Второй шаг                                             |
|                                                            |
| Где получить: ...                                          |
| Источник: официальный ресурс · проверено ДД.ММ.ГГГГ        |
| [Открыть источник] [Начать заново]                          |
+------------------------------------------------------------+
| Справочная информация, не официальное решение госоргана.   |
+------------------------------------------------------------+
```

## Состояния интерфейса

- `idle`: пример запроса и поле ввода;
- `loading`: блокировка повторной отправки и индикатор шага;
- `clarification`: один вопрос и до четырёх вариантов ответа;
- `ready`: карточка маршрута с источником;
- `unsupported`: список пяти поддерживаемых ситуаций;
- `content_unavailable`: услуга распознана, но сведения ещё не проверены;
- `error`: понятное сообщение и возможность повторить запрос.
